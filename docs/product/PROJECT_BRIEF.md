# Project Brief

## 一句话定位

LinguaLoop 是一个开源的对话式语言学习平台，用真实输入材料驱动个性化对话练习，并把每次练习沉淀为可复盘、可追踪、可继续的学习循环。

## 为什么做

很多语言学习工具把输入、对话、纠错和复习拆成多个孤立环节。学习者看完材料后，很难把刚刚遇到的表达转化为可输出能力，也很难知道下一次该练什么。LinguaLoop 希望把这些环节连接起来，让学习过程更像一个可持续迭代的训练系统。

已有 input-driven learning workflow 的实践说明，一个有效系统不应只问“这段材料讲了什么”，还应先识别用户面对的学习现象：看得懂但说不出、能认出但不能及时检索、语块在输出时断裂、搭配和语气不能迁移、延迟复习后遗忘等。LinguaLoop 的产品设计应从这些现象出发，再选择合适 Pattern，而不是把所有材料都压进同一套课程模板。

## 目标用户

- 有明确目标语言、已经能进行基础阅读或听力输入的学习者
- 希望用真实材料练口语、写作或对话表达的人
- 想把视频、文章、字幕、播客转写等输入材料转成练习任务的人
- 愿意通过 AI 对话获得即时纠错和复盘的人

## 核心原则

- 真实输入优先：练习应尽量来自用户真实接触过的材料，而不是完全随机生成。
- 学习现象优先：系统应先判断用户当前需要解决的是输入理解、语块 noticing、对话输出、口语检索还是延迟复习，再选择 Pattern。
- 对话不是终点：对话必须服务于理解、输出、反馈和复习。
- 反馈要可行动：纠错不只告诉用户错了什么，还要给出下一次可练的表达。
- 输出才是证据：只有用户真实回答、冷启动输出、复习结果或延迟检索能更新学习状态；展示过内容不等于已经掌握。
- 用户保持控制：难度、语气、纠错强度、目标技能和复习节奏应可调。
- 数据可迁移：作为开源项目，用户学习数据应尽量避免被某个服务锁死。

相关依据见 [Learning Loop Foundation](../research/LEARNING_LOOP_FOUNDATION.md) 和 [Practice Workspace Findings](../research/PRACTICE_WORKSPACE_FINDINGS.md)。

## 第一版体验假设

用户导入一段目标语言材料后，系统生成摘要、关键词、表达点和对话任务。用户进入对话练习，AI 根据材料语境扮演对话伙伴，并在合适时机给出纠错、替代表达和复述任务。练习结束后，系统生成复盘记录和下一次练习建议。

## 非目标

- 不做泛用聊天机器人。
- 不在第一版实现完整课程市场。
- 不在第一版覆盖所有语言学习场景。
- 不把自动评分包装成绝对能力评估；第一版只提供辅助性反馈。
